# Template — Brief créatif hospitality

> À remplir après la découverte client. Ce document est la référence unique pour le designer, le rédacteur, le photographe et le développeur. Chaque rubrique doit tenir en une page maximum ; le détail va dans les spécifications.

## 1. Résumé stratégique (10 lignes)

- **Établissement** : nom, type, lieu, capacité, gamme de prix.
- **Problème à résoudre** : ce que le site actuel (ou l'absence de site) coûte.
- **Objectif principal** et KPI de succès (ex. +30 % de réservations directes, 25 demandes qualifiées / mois).
- **Mode de conversion** : transactionnel / conversationnel / hybride.
- **Contraintes clés** : calendrier, budget, contenus, technique.

## 5. Direction artistique retenue

- Palette : fond principal, fond secondaire, texte, accent, accent secondaire, états (hover, focus, erreur).
- Typographie : famille titres, famille texte, échelle (voir `references/visual-design-system.md`), casse, interlettrage.
- Grille : largeur max, colonnes, gouttières, marges desktop/mobile.
- Formes : rayons, épaisseurs de trait, style de boutons, style d'icônes.
- Photographie : cadrages, lumière, présence humaine, ratio lieu/expérience, shot list (voir `references/photography-video.md`).
- Mouvement : niveau (sobre / mesuré / signature), signature de mouvement unique, règles reduced motion.

## 6. Ton et copywriting

- Ton (3 adjectifs), personne grammaticale (nous / la maison / vous), niveau de langue.
- Champ lexical autorisé / interdit.
- Formules de CTA (découvrir / demander / réserver) et hiérarchie.
- Longueurs cibles : titre hero, accroche, paragraphe, description d'hébergement.

## 7. Architecture

- Sitemap (voir `sitemap-template.md`).
- Parcours principal : entrée → désir → offre → preuve → réservation (nombre de clics maximal : 3 pour atteindre une chambre, 1 pour atteindre le moteur depuis n'importe quelle page).
- Parcours secondaires : contact humain, cadeau, événements, propriétaires (collection).
