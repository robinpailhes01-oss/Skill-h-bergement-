# Pages hébergements — chambres, suites, villas, chalets, cabanes, maisons

> La page hébergement est la page qui convertit : c'est là que le visiteur décide. Elle doit permettre de se projeter (émotion), de vérifier (faits), et d'agir (réserver ou demander) sans quitter la page. Niveaux : Indispensable / Recommandé / Signature premium.

## 0. Pages observées dans le benchmark (2026-09-04)

| Site | Page | Structure observée | Forces | Manques |

Enseignement principal : la page de Le Collectionist est le modèle fonctionnel (tout y est) ; FORESTIS et Corazón sont les modèles émotionnels (silence, nom, ton). La page idéale combine les deux : l'ordre de FORESTIS/Corazón (image → nom → promesse → faits en une ligne → description) puis la complétude de Le Collectionist (prix, conditions, humain, suggestions), avec un CTA sticky.

## 1. Ordre des sections (Indispensable)

| # | Section | Contenu | Pourquoi à cet endroit |
|---|---|---|---|
| 1 | Hero | image ou vidéo signature de CET hébergement (pas une vue générique), nom propre, promesse ≤ 15 mots, ligne de faits (m² · personnes · lits · vue · extérieur), prix « à partir de » ; CTA principal + secondaire | décision émotionnelle immédiate + faits pour qualifier |
| 2 | Galerie | 8–15 images ordonnées : ensemble → lit → salle de bain → détail → vue → extérieur → moment de vie ; légendes ; compteur ; lightbox | projection |
| 3 | Description | 60–150 mots : atmosphère, lumière, matières, moments (matin/soir), un détail inattendu | donner envie, différencier |
| 4 | Faits groupés | Confort (lit, literie, climatisation, cheminée) / Salle de bain / Technologie / Extérieur & vue / Accessibilité ; icônes trait ou texte ; accordéons mobile | vérification |
| 5 | Inclus & sur demande | petit-déjeuner, ménage, conciergerie, transferts, chef, soins | extension du panier |
| 6 | Tarifs & disponibilités | prix par nuit ou semaine par saison ; moteur pré-rempli ou calendrier ; conditions (acompte, annulation, caution, arrivée/départ) | transparence, action |
| 7 | Plan (villa, chalet, suite complexe) | niveaux, orientation, distances | réassurance familiale |
| 8 | Réassurance | 2 avis liés à cet hébergement ; garanties ; contact humain avec prénom et délai | lever les doutes |
| 9 | Hébergements complémentaires | 2–3 types (plus grand, plus intime, autre vue) avec prix | ne jamais laisser sortir sans alternative |
| 10 | Expériences liées | 2–3 expériences ou services proches | prolonger le désir |
| 11 | CTA final | rappel + humain | — |

## 2. Éléments de la fiche

| Élément | Niveau | Règle |
|---|---|---|
| Nom | Indispensable | nom propre (lieu, matière, histoire) + type dans le sous-titre et le title SEO ; jamais « Standard / Supérieure / Deluxe » seuls |
| Promesse | Indispensable | ce qu'on y vit, ≤ 15 mots (« Le lever du soleil sur les Dolomites depuis le lit ») |
| Galerie | Indispensable | ≥ 8 images, même traitement, ratios cohérents, première image = la plus forte, une image avec présence humaine ou signe de vie |
| Ordre des informations | Indispensable | émotion → faits → action → détails → alternatives |
| Description | Indispensable | sensorielle, concrète, 60–150 mots, sans superlatifs creux |
| Capacité | Indispensable | personnes, lits (types), lit d'appoint, enfants, PMR |
| Équipements | Indispensable | groupés, complets, honnêtes (pas de « vue mer partielle » cachée) |
| Services | Recommandé | inclus vs à la carte, prix des extras |
| Prix / disponibilité | Indispensable | « à partir de » + saison ; calendrier ou moteur pré-rempli ; villa : tableau saisonnier + frais |
| CTA | Indispensable | Réserver (plein) + Demander / Appeler (secondaire) ; sticky |
| Éléments de projection | Signature premium | « Une journée ici » (matin, après-midi, soir), vidéo de 45–60 s, vue depuis la fenêtre à deux heures |
| Vente de l'expérience | Recommandé | rituels inclus (petit-déjeuner, bain, feu), ce que l'on voit, entend, sent |
| Réassurance | Indispensable | avis, conditions, contact humain, labels |
| Complémentaires | Indispensable | 2–3 hébergements + 2–3 expériences |
| Données structurées | Recommandé | `HotelRoom` / `Accommodation` + `Offer` |

## 3. Page liste des hébergements

- Titre + 1 phrase de positionnement ; filtres uniquement si > 6 types (capacité, vue, extérieur, prix) ; tri par défaut = ordre narratif (signature → classique), pas par prix.
- Cartes : image 4:5 ou 3:2, nom, accroche, ligne de faits, prix « à partir de », « Découvrir » + « Disponibilités ».
- 3 mises en avant puis grille complète ; une carte « Vous hésitez ? Écrivez à [prénom] ».
- Collection : liste par destination avec carte, favoris, tri (prix, capacité, nouveautés), badges de collection (Le Collectionist : Essential / Signature / Iconic), prix par semaine pour des dates données.

## 4. Variantes par modèle

| Modèle | Spécificités de la page |
|---|---|
| Boutique-hôtel | 1 page par chambre ou par famille de chambres (≤ 8 pages) ; description très sensorielle ; « pourquoi cette chambre » ; suggestions |
| 5 étoiles | page par catégorie + sous-catégories en accordéon ; comparateur (m², vue, lits) ; services (majordome, club) ; offres liées |
| Chalet / montagne | plan par niveau, capacité par chambre, ski-in/out, local à skis, jacuzzi/sauna, distance aux remontées, saisons et prix par semaine, chef/ménage, hiver/été |
| Villa | plan, chambres détaillées (lits, salle de bain), extérieurs (piscine chauffée ?, jardin, vue), équipements familiaux, personnel, distances (plage, commerces), tableau saisonnier, frais, conditions, calendrier |
| Insolite | accès (chemin, voiture, marche), confort réel (chauffage, sanitaires, eau, électricité), météo, ce qu'il faut apporter, sécurité, enfants/animaux, nuit minimale ; photos de nuit et par temps couvert |
| Wellness | programme associé, inclusions (soins, repas), durée minimale, praticiens, calme (pas de TV ?), régime |
| Collection | fiche normalisée (faits en ligne, incontournables, chambres, services, prix par semaine, bon à savoir, conseiller, carte, conditions, similaires) |

## 5. Mobile (Indispensable)

- Hero 70–85 svh, nom 30–36 px, ligne de faits sur 2 lignes max, prix visible.
- Barre basse fixe : prix « à partir de » + « Réserver » (ou « Demander ») ; masquée quand le moteur est ouvert.
- Galerie en défilement horizontal avec compteur ; tap = plein écran ; swipe.
- Description : 3 lignes puis « Lire la suite » ; faits en accordéons ; tableau des tarifs en cartes par saison.
- Contact humain : boutons Appeler / WhatsApp.

## 6. Erreurs fréquentes

Une seule page pour toutes les chambres sans détail (Seagate) ; pas de prix (4 sites sur 5) ; CTA uniquement dans le header (FORESTIS) ; sous-menu qui liste toutes les chambres ; galerie réduite à une image de 427 px sans lightbox (Corazón) ; équipements en bloc de capitales ; description copiée d'une chambre à l'autre ; aucune alternative proposée ; conditions cachées dans le moteur ; images de ratios différents ; vue « générique » de l'hôtel en hero de chaque chambre.
