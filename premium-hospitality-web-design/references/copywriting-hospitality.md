# Copywriting hôtelier et hébergement premium

> Objectif : des textes qui font ressentir le séjour, disent la vérité du lieu, et conduisent à l'action. Règles classées Indispensable / Recommandé / Signature premium, avec contexte et risque. Ne jamais recopier les textes des sites de référence ; réutiliser les mécanismes.

## 1. Ton et voix

1. **Choisir une voix et s'y tenir** (Indispensable). Trois options : *la maison parle* (« Ici, … »), *nous* (les hôtes, chaleureux), *vous* (projection du client). Mélanger crée de l'impersonnel. Boutique / maison d'hôtes : « nous » ; 5 étoiles / resort : la maison ou « vous » ; collection : « nous » inclusif + « vous ».
2. **Registre** : soutenu mais parlé ; phrases de 8 à 18 mots ; un verbe fort par phrase ; pas de subordonnées en cascade.
3. **Chaleur avant prestige** (Recommandé). Le luxe se dit par la précision (matière, heure, geste, prénom) et non par les superlatifs. Interdits sans preuve : luxueux, élégant, exceptionnel, unique, prestigieux, raffiné, exclusif, inoubliable, écrin, havre, sublime.
4. **Négation d'un attendu** (Signature premium) : « pas de … : des … ». À utiliser une fois, dans le manifeste.

## 2. Vocabulaire et champ lexical

- Construire un lexique de marque de 30 à 50 mots (matières, lumière, sons, gestes, saisons, lieux, personnes) et l'utiliser partout : titres, alt, microcopies, e-mails.
- Sensoriel concret : « le bois chauffe l'air », « la pierre garde la fraîcheur de midi », « le petit-déjeuner arrive quand vous vous réveillez ».
- Temporel : parler des moments (matin, sieste, heure bleue, dernière lumière) ; le client se projette dans une journée, pas dans une liste.
- Territorial : noms de lieux réels, distances en minutes, noms de producteurs, de sommets, de plages.
- Interdits : jargon hôtelier (« hébergement », « prestations », « établissement » dans les textes visibles), « standard », « supérieure », « deluxe » comme noms de chambre.

## 3. Longueurs

| Zone | Longueur | Note |
|---|---|---|
| Titre hero | 2 à 8 mots | promesse ou tension, pas le nom de l'hôtel (il est dans le logo) |
| Sous-titre hero | ≤ 20 mots | lieu + ce qu'on y vit |
| Titre de section | 2 à 6 mots | sensation ou action |
| Manifeste | 40 à 90 mots | 3 phrases : ce qu'est le lieu, ce qu'on y fait, ce qu'on refuse |
| Accroche carte hébergement | ≤ 15 mots | ce qui distingue cet hébergement |
| Description hébergement | 60 à 150 mots | atmosphère → lumière → matières → moments → un détail inattendu |
| Description expérience | 40 à 100 mots | déroulé + sensation + qui accompagne |
| Avis cité | ≤ 25 mots | avec prénom, ville, date, source |
| Microcopie CTA | 1 à 3 mots | verbe |
| FAQ réponse | ≤ 60 mots | factuel |

## 4. Titres

- Structures qui fonctionnent : *substantif abstrait + concret* (« L'art de la lenteur »), *binôme* (« Pierre et lumière »), *impératif* (« Partagez … »), *lieu + moment* (« Les Dolomites à l'heure bleue »), *négation* (« Pas d'horaires »).
- Éviter : « Bienvenue », « Notre hôtel », « Nos chambres », « Découvrez », questions rhétoriques vides.
- Un seul titre par section ; le sur-titre (petite ligne au-dessus) porte la catégorie (« Suites », « Table », « Spa ») ; le titre porte la sensation.

## 5. Transformer une prestation en expérience (méthode)

1. Prestation brute : « Petit-déjeuner buffet de 7 h à 10 h 30 ».
2. Ce que vit le client : se réveiller sans réveil, descendre quand il veut, manger dehors.
3. Détail vrai : le pain vient du village, les œufs de la ferme voisine, la terrasse regarde l'est.
4. Phrase : « Le petit-déjeuner attend votre réveil, jusqu'à la fin de la matinée, sur la terrasse qui reçoit le premier soleil. Pain du village, œufs de la ferme d'en face. »
5. Faits en note : horaires, inclus ou non, options.
Appliquer à chaque équipement clé (spa, piscine, cheminée, vue, conciergerie).

## 6. Caractéristiques techniques

- Toujours présentes, toujours après l'émotion : ligne de faits sous le nom (« 55 m² · 2 personnes · 1 chambre · terrasse · vue Dolomites »), puis groupes (Confort / Salle de bain / Technologie / Extérieur / Services).
- Chiffres exacts (m², lits, étage, distances) ; pas d'approximations flatteuses.
- Prix : « à partir de », par nuit ou par semaine, taxes indiquées, saison précisée.

## 7. CTA et hiérarchie des actions

| Intention | Verbe | Où | Note |
|---|---|---|---|
| Explorer | Découvrir, Voir les suites, Explorer les maisons | cartes, sections | jamais « En savoir plus » seul |
| Comparer / choisir | Voir les disponibilités, Vérifier les dates | page hébergement | ouvre le moteur pré-rempli |
| Demander | Demander un séjour, Écrire à [prénom], Échanger avec un conseiller, Planifier un appel | modèles conversationnels | promesse de délai de réponse à côté |
| Réserver | Réserver, Réserver cette suite, Réserver du 12 au 15 mars | header, hero, barre basse | la seule action en bouton plein |
| Offrir | Offrir un séjour | header secondaire, footer | — |
| Restaurer / soigner | Réserver une table, Réserver un soin | pages table/spa | — |

Règles : un seul bouton plein par viewport ; les autres actions en liens soulignés ou boutons contour ; le verbe du CTA correspond à ce qui se passe réellement après le clic (ne pas écrire « Réserver » si l'on arrive sur un formulaire de demande).

## 8. Microcopies et réassurance

- Près du CTA : « Meilleur tarif garanti en direct », « Annulation gratuite jusqu'à 7 jours », « Réponse sous 24 h », « Petit-déjeuner inclus », « Sans frais de réservation ».
- Formulaires : labels explicites (« Dates souhaitées », « Avec qui voyagez-vous ? »), aide contextuelle, message de confirmation avec prochaine étape et prénom de la personne qui répondra.
- Erreurs : dire quoi corriger, jamais « erreur inconnue ».
- Vides : « Aucune maison ne correspond à ces dates ; [prénom] peut vous proposer des alternatives ».

## 9. Structures de pages (squelettes de texte)

**Accueil** : titre hero (promesse) → sous-titre (lieu + vie) → manifeste 3 phrases → « Les hébergements » avec une accroche par carte → « Ce que l'on vit ici » 3 expériences → table / spa en 2 phrases → preuve (2 avis, 3 distinctions) → offre directe → « Nous écrire » avec prénom → newsletter.

**Hébergement** : nom → promesse (≤ 15 mots) → ligne de faits → description 60–150 mots → « Ce qui est inclus » → « Bon à savoir » → tarifs/conditions → « Vous aimerez aussi ».

**Expérience** : titre sensation → sur-titre catégorie → déroulé (quand, combien de temps, avec qui) → ce que l'on ressent → infos pratiques → hébergement recommandé.

**Histoire** : origine (personnes, bâtiment) → ce que l'on a voulu faire → ce que l'on refuse → aujourd'hui (équipe, rituels) → invitation.

**Contact** : promesse de réponse → moyens (téléphone, WhatsApp, e-mail) → accès (temps depuis aéroport/gare) → carte → FAQ (5 à 8 questions réelles).

## 10. Multilingue

- Rédiger dans la langue de la marque, traduire par des humains, adapter les références culturelles ; conserver les noms propres d'hébergements ; ne pas traduire la signature de marque si elle est courte (« Nowhere Else »).

## 11. Erreurs qui font bas de gamme

- Adjectifs empilés sans faits ; « Bienvenue sur notre site » ; points d'exclamation ; « n'hésitez pas » ; capitales illisibles sur mobile ; textes justifiés ; noms de chambres génériques ; CTA « Cliquez ici » ; promesses non tenues par le moteur (prix, disponibilité).
